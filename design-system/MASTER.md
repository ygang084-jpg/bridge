# BRIDGE SAFE — Design System Master

이 문서는 이 서비스의 **유일한 디자인 소스 오브 트루스**입니다. 화면을 만들 때는 이 문서를
그대로 적용하고, 화면별 예외가 필요하면 `design-system/pages/[screen].md`에 편차만 기록합니다.

## 0. 왜 이런 선택을 했는가 — 톤의 근거

업종 일반 추천(공공/정부 서비스 = 진지한 네이비, 정부 대시보드 톤)을 그대로 쓰지 않고,
**3단계 페르소나 워크시트**의 다음 항목을 우선 반영했습니다.

| 페르소나 근거 | 디자인 결정 |
| --- | --- |
| "화면에 들어와 **3초 안에** '오늘 괜찮은지' 답이 안 보이면 이탈한다" | 상세 화면 최상단에 큰 한 문장 요약 1개만. 정보 밀도는 그 아래로 미룬다 |
| "내비·날씨앱은 능숙하나 **새 앱 설치는 꺼림** (웹앱 선호)" | 네이티브 앱 느낌의 화려한 온보딩·스플래시 없이, 브라우저에서 바로 읽히는 **문서형 웹 UI** |
| "AI 요약과 공식 안전등급은 반드시 분리 표기" + "AI 분석은 참고용" 고지 상시 노출 | AI 요약 카드와 공식 데이터 카드를 시각적으로 다른 컨테이너(색·라벨)로 분리. 고지문은 매 화면 하단 고정 |
| "경고가 너무 잦으면 결국 무시하게 된다" | 위험/주의 상태를 **점멸·강한 채도의 경고색**이 아니라 **저채도 신호색 + 아이콘 + 문장**으로 조용히 표현. 평상시(문제 없음)는 오히려 가장 차분한 화면이 되어야 한다 |
| "결국 감으로 건넌다" / "확인할 방법이 없다" | 모든 데이터 항목에 **출처와 기준일(갱신 시각)을 항상 병기**. 값이 없으면 숨기지 않고 '정보 없음'을 명시 |
| 목표 사용자 = 30~50대, 자차 통근, 기술 친숙도는 보통 이하 가정 | 작은 텍스트·저대비·트렌디한 초경량 폰트 지양. 본문 16px 이상, 명도 대비 AA 이상 확보 |

**한 줄 요약 톤:** *과장하지 않는, 관공서스럽지 않은, 차분하고 근거를 보여주는 안내문.*
공공기관 사이트의 딱딱함도 아니고, 날씨앱의 화려한 경고 배너도 아니다.

## 1. 컬러 토큰

기준: Government/Public Service 팔레트(신뢰감의 네이비) + Status Page 팔레트(저채도 3색 신호)를
결합. 경쟁사(내비앱)처럼 채도 높은 원색 경고를 쓰지 않고, 톤 다운된 신호색을 쓴다.

### 1-1. 브랜드 · 중립 (Neutral / Brand)

| 역할 | Hex | CSS 변수 | 용도 |
| --- | --- | --- | --- |
| Primary | `#0F172A` | `--color-primary` | 헤더, 주요 버튼, 강조 텍스트 — 신뢰·공공성 |
| On Primary | `#FFFFFF` | `--color-on-primary` | Primary 위 텍스트 |
| Accent | `#0369A1` | `--color-accent` | 링크, 보조 CTA('오늘의 위험요인 보기' 등) |
| On Accent | `#FFFFFF` | `--color-on-accent` | |

| Surface (Card) | `#FFFFFF` | `--color-surface` | 카드, 리스트 아이템 |

### 1-2. 상태 신호색 (저채도 3색 — 아이콘+텍스트와 항상 함께 사용)

색으로만 의미를 전달하지 않는다 (`color-not-only`). 모든 배지는 **아이콘 + 상태어 + 색**의 3중 표현.

| 상태 | 배경 | 텍스트/아이콘 | 사용 예 |
| --- | --- | --- | --- |
| 정보 있음 / 안전 (Safe) | `#ECFDF3` | `#15803D` | "정보 있음", "특보 없음", 배지 |
| 오래됨 / 주의 (Caution) | `#FFFBEB` | `#B45309` | "정보 오래됨", "강풍 주의" |
| 위험 / 통제 (Danger) | `#FEF2F2` | `#B91C1C` | "통행 제한", "기준치 초과" |
| 정보 없음 (Unknown) | `#F1F5F9` | `#64748B` | "정보 없음" — 회색으로 명확히 구분, 위험색과 혼동 금지 |
| AI 생성 표시 | `#EFF6FF` | `#1D4ED8` | "AI 요약" 배지 — 공식 데이터와 구분되는 유일한 색 |

> **금지:** 순수 채도 100%의 신호등 빨/초 (`#FF0000`/`#00FF00`), 점멸 애니메이션, 배지 색만으로
> 상태를 표현하는 것. 위 5개 상태색 외의 임의 색 추가 금지.

## 3. 여백 · 그리드

8px 기준 스케일. 모바일 웹 단일 컬럼, 최대폭 480px 중앙 정렬(모바일 우선이지만 데스크톱에서도
좁은 정보성 문서처럼 보이게 — 지도 대신 목록형이므로 넓은 그리드가 필요 없음).

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `space-xs` | 4px | 아이콘-텍스트 간격 |
| `space-sm` | 8px | 배지 내부 패딩 |
| `space-md` | 16px | 카드 내부 패딩, 화면 좌우 마진(모바일) |
| `space-lg` | 24px | 카드 사이 간격, 섹션 내부 간격 |
| `space-xl` | 40px | 섹션 간 간격 |
| `container-max` | 480px | 콘텐츠 최대 폭 (`mx-auto`) |

## 4. 형태 · 입체감 (Shape & Elevation)

- **모서리:** 카드 `rounded-xl`(12px), 버튼/인풋 `rounded-lg`(8px), 배지 `rounded-full`(pill)
- **그림자:** 최소한만 사용. 카드는 `shadow-sm` (0 1px 2px rgba(15,23,42,0.06)) + `border` 1px 조합으로
  구분한다. **떠 있는 느낌의 강한 그림자·글래스모피즘·블러 배경은 사용하지 않는다** — 공공 정보
  서비스가 화려해 보이면 신뢰가 아니라 의심을 산다.
- **강조는 색과 굵기로, 입체감으로 하지 않는다.**

## 5. 아이콘

- 라이브러리: **Phosphor Icons** (line/regular 스타일 고정, weight 1.5px 상당)
- 이모지 사용 금지 (서비스명 로고 "🌉"만 예외 — 브랜드 워드마크에서만 1회 사용)
- 상태 배지는 항상 아이콘 24px + 라벨 텍스트를 함께 배치 (`CheckCircle`=안전, `WarningCircle`=주의,
  `XCircle`=위험/통제, `Question`=정보없음, `Sparkle`=AI)
- 터치 타깃 최소 44×44px (아이콘이 작아도 버튼 영역은 패딩으로 확보)

## 6. 컴포넌트 규칙

### 6-1. 요약 카드 (AI 한 문장 요약)
- 화면 최상단, `bg-ai-bg` 톤이 아니라 **surface 배경 + 좌측 4px `accent` 보더 바** + 우상단에
  작은 "AI 요약" pill(`ai.bg`/`ai.fg`)로 AI임을 표시.
- 바로 아래 캡션으로 "AI 분석은 참고용이며 공식 안전진단을 대체하지 않습니다" — 이 문구는
  **모든 화면 하단에도 반복** (한 번만 보여주고 사라지면 안 됨).
- 등급 숫자·영문 코드를 그대로 반복하지 않는다 (예: "안전등급 B입니다" 금지 — 페인포인트 ②).

### 6-2. 공식 정보 리스트
- 5항목(준공연도·안전등급·최근 점검일·통행제한·관리기관)을 key-value 리스트로.
- 각 항목 우측 하단에 캡션 크기로 "출처 · 기준일" 병기. 값이 없으면 `unknown` 배지로 "정보 없음"
  — 빈칸으로 두거나 숨기지 않는다.

### 6-3. 상태 배지 (교량 목록 / 위험요인 공통)
- pill 배지, 배경 tint + 텍스트(진한 색) + 좌측 아이콘. 색만으로 끝내지 않는다.
- 목록 단계에서부터 배지를 보여준다 (상세 진입 전에 정보 상태를 알 수 있어야 함).

### 6-4. 위험요인 항목
- "안전합니다" 같은 판정형 문장 금지. "오늘 특보나 기준치 초과는 없습니다" 같은 **사실 서술형**
  문장만 사용 (Won't: AI 자체 위험도 산정).
- 항목당 상태 + 실제 관측값(수치) + 출처 + 관측 시각을 한 줄에.

### 6-5. 정보 없음 화면
- 빈 화면·에러 화면처럼 보이지 않게, 아이콘 + 문장 + 관리기관 문의처 + '목록으로' 버튼을 갖춘
  완결된 카드로 구성.

### 6-6. 버튼
- Primary: `bg-primary text-white`, 하나의 화면에 주 CTA는 1개만.
- Secondary/텍스트 링크: `text-accent`, 밑줄 없음, hover 시 밑줄.
- 모든 버튼 `min-h-[44px]`, `cursor-pointer`, `transition-colors duration-150`.

## 7. 모션

- 지속시간 150–250ms, `ease-out` 진입 / `ease-in` 이탈.
- 경고성 요소에 점멸·반복 애니메이션 금지(경고 피로 방지 원칙과 직결).
- `prefers-reduced-motion` 존중 — 모든 transition에 `motion-reduce:transition-none` 고려.

## 8. 접근성 체크리스트

- [ ] 본문 대비 4.5:1 이상 (위 색 토큰은 사전 검증됨)
- [ ] 상태는 색+아이콘+텍스트 3중 표현
- [ ] 터치 타깃 44×44px 이상, 8px 이상 간격
- [ ] 포커스 링 가시성 확보 (`focus-visible:ring-2 ring-accent`)
- [ ] 뷰포트 375px에서 가로 스크롤 없음
- [ ] 이미지/아이콘에 대체텍스트 또는 aria-label

## 9. 하지 않는 것 (Anti-pattern — 이 프로젝트 한정)

| 금지 | 이유 |
| --- | --- |
| 글래스모피즘 / 강한 블러 / 네온 다크 대시보드 (스마트시티풍) | 페르소나는 화려함이 아니라 "지금 건너도 되는지"에 대한 신속하고 차분한 답을 원함 |
| 원색 신호등 색(순수 빨강/초록), 점멸 배지 | 경고 피로 방지 원칙(페인포인트 ④)과 직접 충돌 |
| 지도, 온보딩 슬라이드, 스플래시 애니메이션 | 워킹 스켈레톤 범위(Must만) 밖. 앱 설치 거부감 있는 사용자에게 "가볍게 웹처럼" 보여야 함 |
| 이모지 아이콘 (🌉 워드마크 제외) | Phosphor 라인 아이콘으로 통일 |
| "안전합니다"/"위험합니다" 식 AI 판정 문장 | 4단계 Won't("AI 자체 위험도 산정") 및 최대 리스크 통제 원칙 |
| 등급 숫자·코드를 그대로 반복하는 요약 | 페인포인트 ②(등급 의미를 모름)를 해결하지 못함 |

## 10. 페이지 오버라이드

화면별 예외가 생기면 `design-system/pages/[screen].md`에 "이 화면만 다른 점"만 짧게 적는다.
현재는 5개 화면 모두 이 MASTER 규칙을 그대로 따르며, 오버라이드 파일은 없다.
