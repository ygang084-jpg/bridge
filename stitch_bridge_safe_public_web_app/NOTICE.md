# ⚠ 배포 금지 — AI 생성 디자인 목업

이 폴더는 Google Stitch 로 만든 **초기 시각 탐색용 목업**이다. 제품 코드가 아니고,
어떤 화면도 실제 데이터로 동작하지 않는다.

## 왜 배포하면 안 되는가

`code.html` 파일들에 아래가 들어 있다.

| 문제 | 위치 |
| --- | --- |
| **실재하지 않는 정부기관명** — `국가교량안전처` · `국가 교량 안전국` · `국가교량안전청`, `© 2024 국가교량안전처` | `bridge_safe_3` · `bridge_safe_4` · `bridge_safe_5` · `bridge_safe_7` |
| **판정 UI** — `D등급 - 위험`, `위험 경고` | `bridge_safe_7` |
| **AI 분석 문구** — `AI가 분석하는 실시간 안전 데이터`, `AI가 분석하여 관련 기관에 신속하게 전달` | `bridge_safe_2` · `bridge_safe_3` · `bridge_safe_6` |
| 삭제된 기능(시민 제보)의 화면 | `bridge_safe_2` · `bridge_safe_3` |
| 외부 이미지 URL(`googleusercontent.com`) 직접 참조 | 여러 파일 |

첫 항목이 가장 위험하다. 공개 URL 에 올라가면 **존재하지 않는 정부기관의 발표처럼
읽힐 수 있다.** 나머지도 현재 제품 원칙과 정면으로 어긋난다 —
PRD §2.2 는 안전성 판정을 하지 않기로 했고, 시민 제보 기능은 v0.4 에서 삭제되었고,
요약은 AI 가 만들지 않는다(§15.1).

## 조치

- 루트 `.vercelignore` 에 이 폴더를 넣어 배포 대상에서 제외했다.
- 앱이 저장소 루트로 옮겨진 뒤(2026-08-19)에는 버셀이 이 저장소 전체를 올린다. 그래서
  이 폴더가 빠지는 근거는 위 `.vercelignore` 한 줄뿐이다 — 지우지 말 것.

## 남은 결정

**이 폴더를 저장소에서 지울지는 결정되지 않았다.** 저장소가 공개라면 GitHub 에서
그대로 읽힌다. 디자인 기록으로 남길 가치가 있다면, 최소한 위 기관명들을
`(가상 기관)` 같은 표기로 바꾸는 것을 권한다.
